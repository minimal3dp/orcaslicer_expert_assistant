## 📖 Documentation by Topic

### Materials
Learn about the 28 supported materials:
- Standard: PLA, PLA+, HTPLA, PLA variants (silk, wood, CF, metal, glow)
- Engineering: PETG, ABS, ASA, Nylon, PC
- Flexible: TPU 95A, TPU 85A
- Support: PVA, PVB, HIPS
- High-Performance: PEEK, PEKK, PPSU, ULTEM

**See:** [User Guide - Material Selection](USER_GUIDE.md#material-selection-guide)

### Print Goals
Understanding the four priority sliders:
- **Mechanical Strength** (4 types: Z-axis, XY-plane, Flexural, Compressive)
- **Build Time / Speed**
- **Surface Quality**
- **Dimensional Accuracy**

**See:** [User Guide - Understanding Sliders](USER_GUIDE.md#understanding-the-sliders)

### Material Warnings
10 types of warnings for special requirements:
- 🔧 Hardened Nozzle Required
- 🏠 Enclosure Required
- 💧 Must Be Dried (hygroscopic)
- 💨 Ventilation Required
- ⚠️ Difficult to Print
- 📉 Prone to Creep
- ☀️ UV Resistant
- ⚙️ Low Friction
- 🧪 Chemical Resistance
- 🔥 Annealable

**See:** [User Guide - Material Warnings](USER_GUIDE.md#reading-material-warnings)

### OrcaSlicer Settings
Every setting with direct links to official documentation:
- Quality: Layer Height, Walls, Infill
- Speed: Outer Wall, Inner Wall, Sparse Infill, Acceleration
- Temperature: Nozzle, Bed
- Advanced: Line Width, Seam, Ironing, Shrinkage, Arachne

**See:** [User Guide - Settings Reference](USER_GUIDE.md#orcaslicer-settings-reference)

### Troubleshooting
Common issues and solutions:
- Weak/breaking parts
- Slow print times
- Poor surface quality
- Dimensional inaccuracy
- Warping and lifting
- Stringing and blobs
- Material-specific issues

**See:** [User Guide - Troubleshooting](USER_GUIDE.md#troubleshooting)
